1. Installing and starting

The app runs on Python 3.9 or newer, on Windows, macOS and Linux.

  1. Install Python from python.org. On Windows, tick Add python.exe to PATH during the installation.
  2. Unpack the archive anywhere you like. Keep its folder together: the app's files import each other.
  3. Open a terminal in the unpacked folder (the one that holds main.py) and install the libraries the app uses: 
    python -m pip install -r requirements.txt
  4. Start the app: 
    python main.py
The app never installs anything by itself. If a library is missing, the feature that needs it tells you what to install, and the rest of the app keeps working.

On Linux, tkinter (the window toolkit) is a system package: sudo apt install python3-tk on Debian and Ubuntu, sudo dnf install python3-tkinter on Fedora.

2. The window

Units, at the top left, apply to every tab at once. They change how numbers are written and typed. Every calculation is done in SI underneath, so switching units never changes a result. Pick the convention before you type values in, so that the numbers you type mean what you expect.

The window title gives the version and its date, then the Excel file the tab in front is drawing, for example Structural Simulator v32 · 03/10/2026 — roof_iterations.xlsx. When the drawing did not come from a file it reads Truss drawing, Stereo drawing and so on.

About…, at the top right, shows the licence, the open-source licences of the libraries the app runs on, and this guide.

Each tab has its own drawing area, a toolbar above it and a side panel. Most drawing areas zoom with the mouse wheel and pan with the middle button. Hover over a control to see a short explanation. A grey hint that ends in more… opens when clicked.

4. The Truss tab, step by step

Start from an example

Examples… opens a library of nine trusses: Warren, Pratt, Howe, king-post, Fink, a wall bracket, a Vierendeel girder, and two that make a point (a missing diagonal, and idle rods). Each comes with steel sections already chosen and a short lesson: what to look at and what to try. The lesson card sits over the drawing; close it with ×.

Or draw your own

  1. Node: click to place joints on the grid (one square is one metre).
  2. Rod: click two joints to join them.
  3. Support: pick joints, then a pin, a roller or a fixed support.
  4. Load: pick joints and give the force in kN.
  5. ▶ Analyze structure.

The line under Analyze says whether the truss can stand, before you solve it: how many ways it could move, and how many rods or supports it has to spare. If it cannot stand, the analysis shows the motion as an animation, so you can see which bay folds.

Reading the result

  • Red rods are pulled (tension), blue rods are pushed (compression). Dashed rods carry nothing; Hide zero-force rods removes them to show the path the load takes.
  • Live re-solves a moment after every edit on small models.
  • Right-click a support to switch it off and see what happens without it.
  • Simple / Advanced (the Advanced tools box) shows or hides the drafting tools, plates and span loads.

Is it strong enough?

  1. Give every rod family a steel section: in the Rod family / profile box (Advanced), Manage profiles… → Steel section…. The library examples already have them.
  2. Tick Colour by utilisation: green is lightly used, red is at capacity. The results list the most used rod and the deflection against span/300.
  3. Explain rod… shows the CIRSOC 301 check of the selected rod (or the most used one), step by step, with its own numbers.
  4. Self-weight adds the rods' own weight to the loads.

Play, compare, buckle, hand in

  • Load % and ▶ Play load raise the load from nothing to full and name the first rod to reach its capacity, and at what share of the load.
  • The Score line gives the weight, the load carried and whether the design passes. For an example, the lightest passing design is remembered.
  • Keep variant stores up to three solved designs; Compare… shows them side by side at one scale.
  • Buckling… finds the load factor at which the truss buckles in its own plane, the shapes it buckles into, and the second-order load–deflection curve.
  • Export PDF writes the report: cover, geometry with dimensions, forces, deformed shape, reactions, the rod table and the step-by-step check of the most used rods. Every drawing is to scale.

5. The Stereo tab in brief

The mode rail on the left takes you through the work in order: Build (grid family, dimensions, examples), Shape, Support, Load, Section (what the rods are made of), Add-ons (columns, beams, the crane), Module, Analyse and Results. A structure comes from a generator (flat grids, vaults, domes, bridges, surfaces defined by a formula or by control points) or from an Excel file, and can be edited rod by rod.

Rods can be steel (from the catalogue), timber (CIRSOC 601) or aluminium (CIRSOC 701: tubes, rectangular tubes and solid bars in thirteen alloys). The analysis is a full 3D stiffness solution; the results colour the structure by force, utilisation or moment, and every rod can be explained step by step. The PDF report has plan, elevations and axonometric views, all to scale, with a sheet chooser.

The crane is a lifting calculator. Select three or more joints of a piece (or choose a group in the Lift box) and press Lift the selected nodes: the hook goes straight over the piece's centre of gravity and a sling runs to each joint. No supports are added and there is no mast. The panel then shows the piece's weight, the hook load, each sling's length, angle and force, the rope diameter it needs and the standard size to use, and a balance check that reads 0.00 kN when the piece goes straight up. ▶ Analyze lift solves only what is lifted, under its own weight times the dynamic factor, and greys out the rest; ▶ Analyze returns to the service loads, in which the slings play no part. The lift goes into the Excel workbook (Lift results, Lift rods and Cranes sheets, read back on import) and the PDF.

Working with groups. The bar over the 3D view always says which group is current, what is selected and what a lift would take; click a name in it to step back up. Double-click a rod to make its group current (again: the group above it). The current group is highlighted, and Dim others, Group # names and Group colours are in Display. With Pick inside group on, clicks and boxes only take that group's joints. A group can be hidden, or left out of the analysis. If Analyze finds pieces standing on nothing, it names them and offers to leave them out, lift them with a crane or give them supports.

Comparing iterations. Iterations: tags, lift plan, compare… tags each group with its iteration, stage (truss, module, roof) and position, proposed from the group names. Check lifts runs every planned lift at once and the Compare table shows, slot by slot and iteration by iteration, the weight, the worst rod, the sling forces and lengths and the rope size; Export Excel adds it as the Compare sheet.

The group list is a tree. Groups sit inside groups, so the list shows them as branches you can open and close. Drag a group onto another to move it inside it; drop it on empty space below the rows to bring it back to the top. Ungrouped is not a group, so nothing goes inside it. A group cannot be dropped inside itself or inside its own branch, because nothing can contain itself. Double-click a branch to make it current and work inside it.

Piece marks: which of these are the same, and how many. Tick Show on the list in the Piece marks box and identical pieces get one mark and a count, the way a fabrication drawing does. The marks are worked out from the geometry every time, never stored, so they cannot fall out of step with the model. Same to sets how close two pieces must be to count as one: raise it and near-identical pieces merge, lower it and they separate. It errs on the side of calling pieces different on purpose, because marking two identical trusses apart costs you one extra drawing, while marking two different trusses the same sends the wrong steel to site. Schedule… lists them.

Issued numbers stay put. Once you have sent drawings out, press Issue numbers…: from then on a piece keeps the number it was given, even as you go on editing, and new pieces take new numbers. What is saved is not the mark but a record of which shape was given which number, so it can only ever match the right piece or no piece at all. Release numbers undoes it, and so does Undo. The record travels in the workbook on the Mark Register sheet.

Rules. A role is a question about the model, not a fixed list of rods, so it keeps up as the model changes: Save a rule… stores one, Rules… shows them, and they travel with the model on the Rules sheet. A rule can also leave rods out of the analysis. A rule cannot ask about utilisation, force or any other result, and the app will refuse one that tries: those numbers come out of the analysis, so letting them decide what goes in would make the answer depend on itself. Pressing Analyze twice always gives the same numbers. If a rule would leave nothing to solve, the app says so instead of analysing an empty model.

Components: one part, built many times. Right-click a group and choose Make component… to say that this group and its copies are the same part. Copies are then sized together and carry one mark, because a part is fabricated once and installed many times. Make unique (detach this copy) breaks one copy away when it genuinely has to differ. If a copy drifts out of agreement with the rest, the Component entry in that menu says which one and how.

Part files: a component across models. Actions → Save as a part file… writes the current group to a .part.json file; Place a part file… brings it into any model. A part is stored relative to one of its own joints, so dropping it on a joint of your structure lands a joint there and the rods fuse into one structure rather than sitting loose beside it. Placing the same file more than once gives you one component with several copies. Placing it exactly where it already is adds nothing, rather than hiding a second rod inside the first.

6. Excel, PDF and SketchUp

  • Excel: most tabs export their model and results to a workbook and read a model back from one. Excel needs the openpyxl library (installed by requirements.txt). A Stereo workbook also carries the grouping: Groups (the tree, and which groups are components or left out), Scene, Rules, Mark Register and a Piece Marks schedule. The marks sheet is written for you to read; the model itself works them out afresh each time.
  • PDF reports (Truss and Stereo) need matplotlib (also in requirements.txt). They are A4 landscape with a title block on every sheet, in the units selected at the top of the window.
  • SketchUp: the .rbz file in the app folder is a SketchUp extension. Install it from SketchUp's Extension Manager → Install Extension. It works both ways: it exports points and members from a SketchUp drawing to an Excel file the Stereo tab imports, and it builds SketchUp geometry from a model the Stereo tab exported. Groups and components survive the trip in both directions: drawing inside a group no longer loses the geometry, and a component drawn once and copied arrives as one part with copies, not as look-alikes. This needs extension version 0.5.0 or later; check Extension Manager and reinstall the .rbz if yours is older, because earlier versions write no groups and read none back.

The app implements the formulas and cites the clauses and editions it follows. It does not contain the documents themselves; have the current editions at hand.

8. What the results are, and are not

The results are an aid to a qualified professional, who must check them. The app does not replace the design codes it cites, nor the designer's responsibility for the design.
  • Analyses are linear and first-order unless a tab says otherwise (the Cable and Cable Web tabs solve the large-displacement shape; the buckling windows are demonstrations of elastic buckling).
  • Member checks are as implemented, against the cited editions. Where a check is not made, the app says so (for example shear and second-order effects for aluminium rods).
  • Joints and connections are checked only where a tab offers it explicitly (plates in the Truss and Stereo tabs).

9. When something goes wrong

It does not start. Run the environment check from the app folder and read its verdict:

python tools/doctor.py

It names the Python it runs on, every library with its version or the error it raised, and what to install. The most common cause is having installed the libraries into one Python and starting the app with another.

"Analysis failed". Usually the structure can move: a missing support, a missing rod, or a joint that only one rod reaches. The tab says where, and the Truss and Stereo tabs show the motion.

A feature says a library is missing. Install what it names, for example python -m pip install openpyxl, with the same Python that runs the app, and start the app again.
